# VirtualWorks Lab — Task 4: Case Classification & Severity Analysis

## 📌 Overview

This repository contains my submission for **Task 4 of the VirtualWorks Lab Pharmacovigilance Internship**.

The task focuses on **case classification** and basic **severity analysis** of adverse drug reaction (ADR) cases.

Since no real patient dataset was provided, I created a **simulated pharmacovigilance dataset** for training purposes. Each case was assigned structured demographic and clinical attributes so that the cases could be grouped and compared.

---

## 🧪 Project Approach

The project applies the case-classification concept demonstrated in the assigned tutorial.

The simulated cases were classified using:

- Age Group
- Sex
- ADR Category
- Severity
- Seriousness
- Expectedness
- Outcome

These classifications were then used to summarize the dataset and compare the distribution of ADR cases across different groups.

---

## 📊 Classification Dataset

The project contains **12 simulated ADR cases**.

| Attribute | Classification |
|---|---|
| Age Group | Pediatric / Adult / Elderly |
| Sex | Female / Male |
| ADR Category | Dermatological, Gastrointestinal, Cardiovascular, Hepatic, Musculoskeletal, Neurological, Respiratory |
| Severity | Mild / Moderate / Severe |
| Seriousness | Serious / Non-serious |
| Expectedness | Expected / Unexpected |
| Outcome | Recovered / Recovering |

---

## 🔍 Analysis Performed

The simulated dataset was reviewed for:

- Severity distribution
- Serious vs non-serious cases
- Expected vs unexpected events
- Age-group distribution
- ADR category distribution
- Classification of individual cases using structured attributes

The Excel workbook includes summary tables and charts to make these comparisons easier to review.
