# VirtualWorks Task 04 – Case Classification & Severity Analysis

## Overview

This project was completed as part of the **VirtualWorks Pharmacovigilance Internship**.

The objective of Task 4 is to apply the concept of **case classification** to simulated pharmacovigilance data and organize individual ADR cases using relevant patient, event, and case-level attributes. The project also includes severity and seriousness analysis to demonstrate how classified safety cases can be reviewed and compared across different categories.

## Project Objectives

- Classify simulated pharmacovigilance cases using predefined attributes.
- Organize ADR cases according to demographic and safety-related characteristics.
- Categorize cases by severity, seriousness, expectedness, and outcome.
- Identify patterns and distributions within the simulated dataset.
- Present the classified data in a structured and review-friendly format.

## Classification Attributes

The simulated cases are classified using attributes such as:

- **Age Group** – Pediatric, Adult, Elderly
- **Sex** – Male, Female
- **Severity** – Mild, Moderate, Severe
- **Seriousness** – Serious, Non-serious
- **Expectedness** – Expected, Unexpected
- **Outcome** – Recovered, Recovering, Not Recovered, Fatal
- **ADR Category** – Based on the type/system involved in the adverse drug reaction

## Methodology

Each simulated ADR case was assigned a unique case identifier and classified using the selected attributes. The cases were then reviewed across severity, seriousness, expectedness, outcome, demographic characteristics, and ADR category to demonstrate how structured classification can support pharmacovigilance case review and safety-data analysis.

The approach is based on the general concept of **case classification**, where individual cases/subjects can be assigned attributes so that defined groups can be compared and analyzed.

## Key Learning Outcomes

Through this task, the project demonstrates:

- Understanding of case classification in a structured dataset.
- Practical organization of pharmacovigilance case information.
- Differentiation between **severity** and **seriousness**.
- Classification of ADR cases using multiple attributes.
- Basic descriptive analysis of classified safety data.
- Use of Excel for structured pharmacovigilance data handling.
